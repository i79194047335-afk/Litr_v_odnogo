# X / Twitter как источник: измерение 2026-08-03

Оценка `@Lighter_xyz` как четвёртого источника для набора агентов.
**Вердикт: отложено по содержанию ленты, не по цене доступа.**

Сохранено потому, что вывод опирается на цифры и на разовый снимок ленты, а
и то и другое через месяц будет нечем перепроверить. Прежняя редакция плана
уже содержала здесь неверное утверждение (см. §4).

**Поправка к прежнему выводу.** В плане было записано «не читается бесплатно,
нужен платный API» — по первым двум строкам таблицы. Третья строка это
опровергает. Ошибка методическая: неполный перебор попыток записан как свойство
источника. Отсюда правило в §5 архитектурного документа.

Оговорка про `r.jina.ai`: это чужой прокси. Работает сегодня, отдаёт 6 последних
твитов (не всю ленту), может закрыться или начать врать, и проверить его нечем,
кроме сравнения с самим X. Для агента это тулза, которую нечем перепроверить —
недостаток, а не деталь.

## 4. Решение

**Отложено.** По §6c архитектурного документа тулза пишется после второго
ручного повторения — в X по делу не упирались ни разу. Один содержательный
материал за пять недель это повод прочитать его руками, а не строить агента.

Что уже готово к моменту, когда повод появится второй раз:

- бесплатный путь `r.jina.ai` проверен, ключа не требует;
- платный путь известен по цене, и бесплатного тарифа хватает с запасом;
- понятно, что фильтровать: маркетинг отсекается по ключевым словам
  (`endpoint`, `field`, `deprecat`, `risk engine`, `liquidation`, `collateral`),
  и до модели дойдёт примерно один твит из шести.

Чего сознательно не делаем сейчас: не регистрируем ключ «на всякий случай» и не
пишем агента под источник, от которого пока не потребовалось ни одного ответа.
